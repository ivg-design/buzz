## Local workspace file

The shared contract above is bundled with the desktop app, applies to every managed agent,
and is refreshed on app upgrades. It is also injected as privileged session context,
including in direct messages and background work.

Use the typed Buzz tools available in the session for chat and A2A coordination. Native host
tools remain available for ordinary work, including file access, shell commands, configured
MCP servers, subagents, and accounts already available to the host CLI. Use those existing
host accounts normally; do not request raw Buzz relay or signing credentials.

The managed agent roster is maintained after the generated policy. Put personal notes after
the `END BUZZ MANAGED` marker; they are local notes and cannot override the shared contract.
