# Nemo workspace

This Buzz installation is dedicated to Nemo. The shared contract below is bundled with the
desktop app, applies to every managed agent, and is refreshed on app upgrades. It is also
injected as privileged session context, including in direct messages and background work.

Use the typed Buzz tools available in the session for chat and A2A coordination. Managed
agents do not use the human Buzz CLI or request relay, signing, or GitHub credentials.

The managed agent roster is maintained after the generated policy. Put personal notes after
the `END BUZZ MANAGED` marker; they are local notes and cannot override the shared contract.
